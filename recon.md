# Карта рекона: кроссплатформенный ИИ-ассистент (клон функциональности Rustamov JARVIS)

**Что клонируем:** функциональность десктопного JARVIS — HUD и телеметрия, голос и чат, проект/редактор/терминал, плагины, провайдеры и локальные модели.
**Платформа:** Windows + macOS + Linux с первого релиза.
**Для кого:** собственный бесплатный продукт пользователя, интерфейс RU/EN. Бренд — **Амадеус** (Amadeus), в коде рабочее имя `assistant`. Перед запуском проверить товарный знак «Amadeus» и домены.
**Дата:** 2026-11-23.

> **Лицензионная граница.** `RustamovAkrom/JARVIS` — проприетарная лицензия: копирование, изменение, распространение и производные работы запрещены без письменного разрешения. `Srijan-D/Jarvis-AI-Assistant` — без лицензии, то есть все права сохранены. Оба проекта используются **только как публичное описание функций и UX-идей**. Код, ассеты, тексты интерфейса, логотипы и конфиги не переносятся. Название и бренд «JARVIS» не используются. Всё пишется с нуля.
>
> Магазинное приложение Chris Engineer — отдельный продукт. Его скриншоты лежат в `replica/screens/store/` как вспомогательный пример простого онбординга, справки и виджета; целевой срез — Rustamov JARVIS.

### Факты о референсе

- Python 3.14, PyQt, PyInstaller; Windows — основной релиз, macOS/Linux поддерживаются.
- У референса Gemini Live — режим по умолчанию; альтернативный пайплайн: STT (faster-whisper / hosted), LLM (локальный или облачный OpenAI-совместимый), TTS (Piper / системные голоса / ElevenLabs). В клоне Gemini не обязателен: основной путь — локальный каскад, Gemini и Yandex/OpenAI — опциональные адаптеры.
- Локальная память: факты и саммари сессий.
- Инструменты: браузер, приложения, файлы, напоминания, окна/рабочий стол, настройки ОС, погода, рейсы, сообщения, код.
- Проект: папка только на чтение для инструмента, редактор, терминал в папке проекта.
- Разрешения на компьютер: пять отдельных (экран, поиск элементов, мышь, клик/перетаскивание, клавиатура) + подтверждения опасных действий.
- Плагины: Python-модули, 20+ штук, не изолированы, запускаются с правами пользователя.
- Локальный веб-дашборд с pairing и опциональным HTTPS.
- Обновления, автозапуск, блокировка PIN/лицо, утренний бриф, wake-word, push-to-talk, курсор-ассистент.
- Языки интерфейса: EN/RU/UZ. Тестовый набор: 84 теста.
- Известные слабые места референса, которые клон должен закрыть: удаление памяти и чата без подтверждения, отсутствие настройки блокировки/лица, тест плагина сохраняет значения до проверки, тема перерисовывается хрупко, нет матрицы DPI, плагины без песочницы, часть настроек без UI.

### Голос пользователей конкурента JARVIS PRO (AMBIONYS)

Источник: приватная группа отзывов «Отзывы | AMBIONYS», темы «JARVIS PRO» и «Популярные вопросы», прочитано 2026-11-23 из аккаунта пользователя. Продукт — платный локальный ассистент для Windows, по заявлению продавца 700+ пользователей. Цитаты обезличены и сокращены.

**Что хвалят**

- «Сегодняшнее обновление — это PEAK… вчера он только на фразы отвечал, а теперь на всё и даже ноутом управляет».
- «Распознавание речи улучшилось… даже тихий микрофон от наушников разбирает».
- «Анализ экрана очень отлично работает, особенно когда просишь стать комментатором в играх».
- «Очень уютный интерфейс», «озвучка стала более живой», «подключение Fish и ChatGPT — весомый вклад».
- «Он сам скачивает доки и программы с интернета, куда скажешь».
- «Открывать другие приложения не отрываясь от игры — очень помогает».
- «Не надо настраивать, всё базовое запрограммировано».

**На что жалуются**

- «Задержка в 1–2 секунды перед новой командой».
- «Иногда не слышит слова, чёткость бы прокачать».
- «Приходится раскошеливаться на нормальный VPN» (для облачных функций).
- «Антивирус не пропускает» — сборка без цифровой подписи, пользователей просят добавлять в исключения.
- «Не хватает базовых функций, например напоминаний… чтобы напоминал в любом чате».
- «Плагины можно где-то скачать?» — каталога и установки из приложения нет.
- «Хотелось бы, чтобы открывал все приложения, но, наверное, нужен полный доступ к компу».
- «Хотелось бы, чтобы он дольше смотрел на экран или делал больше скриншотов — проще играть в шахматы».
- Лимиты бесплатного GPT и необходимость отдельного аккаунта.

## Ядро цикла

Пользователь говорит или пишет запрос; ассистент понимает его, при необходимости смотрит на экран/файл/проект, выполняет действие в ОС (с разрешением и подтверждением) либо отвечает текстом и голосом; HUD и панели показывают состояние, телеметрию и результат.

Клик-путь счастливого сценария: **микрофон → речь → ответ/действие** — 1–2 действия. Текстовый путь: **ввод → Send → ответ** — 2 действия.

## Пользовательские сценарии

```
F01 Первый запуск и выбор режима
    S01 -> язык -> Gemini Live / локальный пайплайн / свой ключ -> проверка -> S02
    happy path: 3–4 шага
    edge: нет сети, невалидный ключ, нет Ollama, слабое железо, пользователь хочет офлайн

F02 Голосовая сессия через realtime-адаптер (опционально)
    S02 -> PTT/микрофон -> S03 слушает -> распознавание -> ответ/инструмент -> S02
    happy path: 1 клик + речь
    edge: шум, нет микрофона, barge-in, обрыв WebSocket, 429, опасное действие

F03 Локальный пайплайн STT → LLM → TTS (основной)
    S02 -> запись -> Silero VAD -> Whisper -> Ollama/OpenAI-совместимый -> Piper/Silero -> ответ
    happy path: 1 клик + речь
    edge: модель не загружена, не хватает RAM, таймаут, нет TTS-голоса, плохое распознавание

F04 Текстовая беседа с контекстом
    S02 -> поле ввода -> Send -> стриминг -> follow-up
    happy path: 2 действия
    edge: длинный контекст, отмена, ошибка провайдера, пустой ответ

F05 Вложение файла и вопрос
    S02/S04 -> скрепка/файл -> извлечение текста -> вопрос -> ответ
    happy path: 3 шага
    edge: большой файл, неподдерживаемый формат, скан без текста, приватность

F06 Скриншот, область экрана, буфер обмена
    S02 -> камера/хоткей -> выделение -> вопрос; буфер -> карточка действия
    happy path: 2–3 шага
    edge: нет разрешения, Wayland, защищённое окно, второй монитор, отмена

F07 Команда ОС с разрешением
    S02 -> «открой…», «громче», «выключи…» -> проверка разрешения -> подтверждение -> выполнение -> лог
    happy path: 1 команда
    edge: нет прав, приложение не найдено, UAC/Admin, macOS Accessibility, Linux WM, отказ пользователя

F08 Проект: открыть и отредактировать файл
    S22 -> выбрать папку -> дерево -> S23 -> правка -> сохранить
    happy path: 4–5 шагов
    edge: путь вне папки, бинарный файл, нет прав, несохранённые изменения, конфликт версий

F09 Терминал в папке проекта
    S24 -> новая сессия -> команда -> вывод -> закрытие
    happy path: 2–3 шага
    edge: процесс завис, неверная папка, опасная команда, закрытие с процессом

F10 Напоминание или задача
    S06 -> создать -> дата/повтор -> уведомление -> выполнено
    happy path: 3 шага
    edge: пропущенное время, смена часового пояса, сон компьютера, дубликат

F11 Фоновое исследование
    S02 -> запрос -> задача в очереди -> прогресс -> отчёт в S07
    happy path: 1 команда
    edge: нет сети, отмена, длинный отчёт, лимит задач

F12 Утренний бриф
    старт дня -> сводка погоды/задач/календаря -> S07
    edge: нет данных, нет сети, отключено пользователем

F13 Плагин: включить, настроить, протестировать
    S16 -> включить -> S17 -> Save/Test -> использовать в чате
    happy path: 4–5 шагов
    edge: сломанный плагин, нет зависимости, неверный ключ, плагин просит опасные права

F14 Панель плагина
    S25 -> открыть -> данные -> действие
    edge: нет ключа, таймаут API, устаревшие данные, закрытие

F15 Память: посмотреть и забыть
    S18 -> поиск -> копировать/забыть -> подтверждение -> удалено
    edge: пусто, массовое удаление, ошибка хранилища

F16 Смена провайдера, модели, голоса
    S15 -> изменить -> Apply -> переподключение сессии -> проверка
    edge: несовместимая модель, нет ключа, нет квоты, откат

F17 Настройка разрешений
    S14 -> включить/выключить -> предупреждение -> применить -> проверить действие
    edge: политика Full, отзыв разрешения во время сессии, ОС запрещает

F18 Удалённый дашборд и pairing
    S26 -> включить -> код -> подключить устройство -> управление -> отозвать
    edge: неверный код, истёк, HTTP без TLS, потеря сети

F19 Обновление приложения
    S21 -> Check -> Download -> Install -> перезапуск
    edge: нет сети, подпись не совпала, места на диске нет, откат

F20 Блокировка и разблокировка
    S27 -> PIN/пароль -> (лицо) -> S02
    edge: три ошибки -> задержка, забыл PIN, камера недоступна, лицо не совпало

F21 Wake-word и push-to-talk
    S08 -> включить -> «слово»/хоткей -> сессия
    edge: ложные срабатывания, конфликт хоткея, нет микрофона, приватность

F22 Смена языка RU/EN
    S08 -> язык -> перезапуск -> S02
    edge: непереведённые строки, длинные строки, RTL не поддерживается

F23 Очистка истории и данных
    S05/S18 -> удалить -> подтверждение -> очистка
    edge: отмена, удаление активной сессии, экспорт перед удалением
```

## Оценка размера

- **Экраны:** 27, из них 8–9 в MVP.
- **Сценарии:** 23, из них 12 в MVP.
- **Сущности:** 27.
- **Сложные части:**
  1. **Голос в реальном времени** — локальный каскад (Silero VAD → Whisper → Ollama → Piper) с barge-in; опционально Gemini Live, Yandex SpeechKit, OpenAI Realtime; задержка и аудиоустройства на трёх ОС.
  2. **Кроссплатформенные команды ОС** — окна, ввод, скриншоты, громкость, выключение; разные API и разрешения (Windows UAC, macOS Accessibility/Screen Recording, Linux X11/Wayland).
  3. **Плагины и безопасность** — своя экосистема, манифест, изоляция процесса, разрешения, обновления, доверие; при этом без песочницы, как в референсе, нельзя.
  4. **Локальные модели** — установка, память, железо, выбор модели, офлайн-режим, лицензии.
  5. **Обновления и подпись** — Windows code signing, macOS notarization, Linux пакеты; Tauri updater.
- **Размер:** **XL** на полный клон с тремя ОС, полным HUD, терминалом, плагинами и дашбордом. **M** на вертикальный MVP (Setup, чат, голос, одна команда, один локальный провайдер). Полный продукт — **L–XL, 2–3 квартала** для небольшой команды; в одиночку — дольше.

### Рекомендуемый первый вертикальный срез

1. Setup: RU/EN + выбор «локальный пайплайн / облачный адаптер» + ключ (для локального не нужен).
2. Главный экран: HUD-заглушка, чат, стриминг, SQLite-история.
3. Голос: PTT + Whisper (локально) + Ollama + системный TTS.
4. Одна команда ОС: открыть приложение — с разрешением и подтверждением.
5. Настройки: тема, язык, провайдер, устройства; справка не нужна.
6. Тесты: миграции БД, permission-gate, один e2e на чат.
