# Референсные скриншоты

Здесь только **референсы для сравнения макетов**. В сборку клона они не попадают.

## `store/`

Скриншоты приложения **Jarvis Assistant** (издатель Chris Engineer) из Microsoft Store:
https://apps.microsoft.com/detail/9pfv17wzr35z

| файл | что на нём |
| --- | --- |
| `S00_store_icon.png` | иконка-треугольник |
| `S01_workspace.png` | главный экран: чат, загрузка файлов, микрофон, поле ввода |
| `S02_settings.png` | настройки: ключи, язык, личность, громкость, модель |
| `S03_help.png` | справка с поиском и разделами |
| `S04_widget.png` | плавающий виджет поверх окон |
| `S05_bug_report.png` | форма баг-репорта |

Это **вспомогательный** UX-референс: целевой продукт клонирует функциональность Rustamov JARVIS, а не магазинное приложение. Магазинные экраны полезны как пример простого онбординга, справки и виджета.

## Ограничения

- Скриншоты магазина — публичные материалы листинга; используются только для внутреннего сравнения.
- Скриншоты и ассеты `RustamovAkrom/JARVIS` не сохранены: у проекта проприетарная лицензия, запрещающая копирование и производные работы.
- Логотипы, иконки и бренд «JARVIS» не используются в клоне.
