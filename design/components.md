# Дизайн-система: Амадеус (HUD-ассистент)

Визуальный язык: интерфейс как приборная панель, а не как чат-приложение. Тёмный фон, тонкие линии, циан как «энергия», янтарь как предупреждение, моноширинные метки. Свечение — только у того, что живо прямо сейчас: микрофон, ядро, активный инструмент. Всё остальное — матовое и спокойное.

Источник направления: референс `pro.mp4` (компактное окно, чат, wireframe-сфера, волна) + HUD-принципы из фильмов о Старке, переосмысленные под читаемый десктопный продукт.

**Главное правило:** HUD не должен мешать работе. Если элемент не несёт состояния, он не светится и не двигается.

| сетка HUD | `hud-grid` | `#12303D` | `#C9DCE8` | фон сцены |
| кольцо HUD | `hud-ring` | `#2C6E85` | `#7FB4C6` | тики, окружности |
| янтарь HUD | `hud-amber` | `#FFB020` | `#A86400` | температура, «думаю» |

**Контраст.** 26 пар проверены в обеих темах, 0 ошибок AA (`contrast.py`). `border-input` держит 3.1–3.6:1 как UI-граница, `on-accent` — 10.6:1 на циане. Менять значения только с повторной проверкой.

**Запреты**
- Не красить большие площади в `accent`: циан — для линий, точек, одного активного элемента.
- Не смешивать циан и янтарь в одном компоненте без смысла: янтарь = внимание.
- Не использовать чистый белый текст (`#FFF`) — только `text`.

## 2. Типографика

| роль | шрифт | размер / интерлиньяж | применение |
| --- | --- | --- | --- |
| display | Exo 2 600/700 | 33 / 40, 46 / 50 | заголовки экранов, крупные цифры |
| title | Exo 2 600 | 19 / 28 | заголовки панелей, модалок |
| body | Inter 400 | 15 / 24 | сообщения, описания |
| body-s | Inter 400 | 13 / 20 | списки, подписи |
| label | JetBrains Mono 500 | 11 / 16, `0.14em`, uppercase | HUD-метки, статусы, кнопки |
| metric | JetBrains Mono 600 | 19–25, tabular | телеметрия, время |
| code | JetBrains Mono 400 | 12.5 / 20 | код, терминал |

Все три шрифта — OFL, с кириллицей. Запасные: `system-ui` / `ui-monospace`.

**Правила**
- Заглавные и разрядка — только для коротких меток (до 3 слов). Длинный русский текст в uppercase не читается.
- Числа всегда `font-variant-numeric: tabular-nums`, иначе телеметрия «дёргается».
- Не использовать больше двух начертаний в одном блоке.

## 3. Сетка, отступы, радиусы

- База отступов: 4 px. Ряд: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64.
- Каркас: статус-строка 28, шапка 52, рельс 56, сайдбар 272, панель 344, сцена HUD 300.
- Контент чата: максимум 940 px, по центру.
- Радиусы: 4 (метки, чипы), 8 (кнопки, поля, карточки), 12 (панели), 16 (модалки), 22 (крупные блоки).
- HUD-сцена — прямоугольник с засечками по углам, не «капсула».

## 4. Движение

| токен | значение | где |
| --- | --- | --- |
| `fast` | 120 ms | hover, фокус |
| `base` | 200 ms | переключения, раскрытие |
| `slow` | 320 ms | панели, модалки |
| `hud` | 1600 ms | вращение колец, дыхание ядра |
| `ease` | `cubic-bezier(.2,.8,.2,1)` | UI |
| `ease-hud` | `cubic-bezier(.45,.05,.55,.95)` | HUD-анимации |

Состояния ядра меняют скорость, а не размер:
`idle` 46 s → `listening` 9 s → `thinking` 1.6 s → `speaking` 3.2 s → `error` стоп + красный.

`prefers-reduced-motion` отключает вращение, волну и дыхание; состояние остаётся видимым по цвету и подписи.

## 5. Компоненты

### 5.1 AppShell / HUD-каркас
- Слои: `statusbar` → `rail | sidebar | stage | panel`.
- Сцена: фоновая сетка 28×28 с маской, виньетка, засечки по углам, скан-линия (7 s, только в `listening`).
- Панели отделены границей 1 px, без тяжёлых теней.
- Состояния: `default`, `focus-within` (рамка циан), `collapsed` (панель скрыта, остаётся рельс).
- a11y: `<main>`, `<nav>`, `<aside>`; порядок фокуса слева направо; скип-ссылка на композер.

### 5.2 StatusBar
- Высота 28, моно 10 px, uppercase, `text-faint`.

- Справа: CPU, RAM, температура, время. Разделитель `·`.
- Состояния: `online`, `offline`, `degraded` (янтарь), `busy`.

### 5.3 Rail
- 56 px, иконки 18 px, активная — циан + полоска слева 2 px + фон 10 %.
- Подсказка при hover (не title-only): маленький тултип справа.
- Клавиатура: `Tab`, `Enter`; активный пункт `aria-current="page"`.

### 5.4 Sidebar / История
- Заголовок `display` 12 px uppercase + счётчик.
- Поиск 32 px с `⌘K`.
- Группы «Сегодня / Вчера / Раньше» с линией-разделителем.
- Элемент: название, время (`mono` 10 px), сниппет 1 строкой.
- Активный: фон 7 % циан + левая граница 2 px.
- Состояния: `default`, `hover`, `active`, `empty`, `loading` (скелет 3 строки).

### 5.5 ReactorCore (ядро)
- SVG 248×248: внешнее кольцо, тики (dasharray), две дуги, wireframe-сфера из 7 эллипсов, ядро-градиент, точка центра.
- Цвета только через `--reactor-*`: в светлой теме ядро контурное, без белого пятна.
- Состояния: `idle`, `listening`, `thinking`, `speaking`, `error`, `muted`.
- Подпись под ядром — `mono` 10 px, меняется вместе с состоянием.
- a11y: `role="img"`, `aria-label="Состояние: слушаю"`; анимация декоративная.

### 5.5.1 Свёрнутый режим (окошко)
- Когда главное окно свёрнуто или убрано в трей, на экране остаётся **аватар-ядро** — то же ядро в миниатюре. Это единственный элемент, который живёт поверх других окон.
- Размеры: `40` — иконка в трее (без подписи и без hover-тултипа), `64` — обычный плавающий аватар, `88` — крупный режим и hover-увеличение.
- Позиция: правый нижний угол, 24 px от края и 60 px от низа (над панелью задач). Перетаскивается, при отпускании прилипает к ближайшему углу и запоминает место для каждого монитора.
- Слой: `always-on-top`, но не перекрывает полноэкранные игры и видео — там он скрывается вместе с окном.
- Активация: только голосом, клики не нужны.
  - Кодовое слово по умолчанию — **«Амадеус»** (рабочее имя бренда, не «Jarvis»), меняется в настройках. Уникальное имя снижает ложные срабатывания по сравнению с обычным словом «ассистент». Слово ловит локальный keyword spotter (openWakeWord / Porcupine), аудио не уходит в облако и не пишется.
  - Сценарий: «Амадеус» → ядро просыпается (`listening`, волны, подпись «Слушаю — говорите») → команда → `thinking` → `speaking` → `idle`.
  - Если после слова 7 s тишины — возврат в `idle` и подпись «Не расслышал». Если команда начинается сразу со слова, она выполняется без паузы.
  - Окно само не разворачивается: ответ идёт голосом и не крадёт фокус из игры или работы. Окно открывается, только если команда просит показать, или по клику.
  - Стоп-слова «стоп» и «отмена» прерывают ответ. `F4` — push-to-talk как альтернатива, `Esc` — свернуть окно. Микрофон выключается в настройках и голосом.
  - В покое аватар приглушён, но кодовое слово продолжает работать. Постоянного свечения микрофона нет: только короткая вспышка при активации — «свечение = состояние».
  - Ошибки: нет микрофона — янтарный бейдж и подпись; нет разрешения — подсказка, как включить; ложные срабатывания лечатся порогом чувствительности и списком похожих слов.
  - Тест: произнести слово в тишине, в шуме, шёпотом и с другого конца комнаты; проверить, что без слова команда не выполняется.
- Состояния и анимация:

| состояние | цвет | движение |
| --- | --- | --- |
| `idle` | циан, приглушённый | вращение 46 s, дыхание ядра |
| `listening` | циан | вращение 9 s, две расходящиеся волны каждые 2.4 s |
| `thinking` | янтарь | вращение 2.4 s, пульсирующее кольцо 1.4 s |
| `speaking` | яркий циан | вращение 3.2 s, волна 1.2 s, ядро дышит 0.9 s |
| `error` | danger | вращение остановлено, бейдж `!` |
| `muted` | `text-faint` | вращение остановлено, перечёркнутая сфера |

- При наведении и фокусе: масштаб 1.06, через 320 ms появляется подпись состояния (`mono` 10 px, заглавными). Клик разворачивает окно, `Esc` сворачивает обратно; `F4` переключает микрофон. Но основной путь — слово, а не клик.
- Покой: через 8 s без действий и при состоянии `idle` аватар гаснет до 45 % и уменьшается до 0.92; hover или фокус возвращают его. Настройка отключаемая.
- Когда окно развёрнуто, аватар скрыт, а его анимации на паузе — правило «один центр внимания».
- a11y: `<button>` с `aria-label="Амадеус: Слушаю. Открыть окно"`, `aria-haspopup="dialog"`, `aria-expanded`; фокус-кольцо `focus`; подпись дублирует состояние текстом. При `prefers-reduced-motion` вращение, волны и дыхание отключены — состояние читается по цвету, бейджу и подписи.
- Аватар — это ядро, а не лицо. Если позже понадобится «живое лицо», оно рисуется внутри того же круга отдельным слоем, состояния и управление не меняются.
- Демо: `collapsed.html`. React: `MiniOverlay.tsx` рисует аватар `CoreMark` (`CoreMark.tsx`) или `ParticleSphere` (`ParticleSphere.tsx`), стили окошка — `.mini-card*` в `mini.css`. Прежний компонент `MiniCore` удалён.

## 6. Правила HUD

1. **Один центр внимания.** В кадре светится либо ядро, либо активный инструмент. Не всё сразу.
2. **Свечение = состояние.** Статичный элемент без свечения. Hover — только граница/фон.
3. **Плотность.** Минимум 12 px между смысловыми блоками; метки не липнут к тексту.
4. **Читаемость важнее эффекта.** Сетка и скан — ≤ 8 % непрозрачности. Текст всегда поверх.
5. **Никаких ложных данных.** Если датчика нет — «—» и «недоступно», а не нули.
6. **Движение объясняет.** Вращение ускоряется, когда ассистент работает; в покое — медленно.
7. **Светлая тема — не инверсия.** В ней HUD контурный, без неоновых ореолов.
