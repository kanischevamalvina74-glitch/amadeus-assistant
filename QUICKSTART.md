# Amadeus — установка и первый запуск

Короткая инструкция для пользователя без опыта программирования. Amadeus работает целиком на вашем компьютере: данные не уходят в облако, аккаунт и оплата не нужны.

## 1. Установка

1. Скачайте файл `Amadeus_0.1.0_x64-setup.exe` (около 315 МБ).
2. Дважды щёлкните по нему.
3. Windows может показать окно **«Windows защитила ваш компьютер»** — это потому, что установщик пока не подписан платным сертификатом. Нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**.
4. Дальше нажимайте **«Далее»**, а в конце **«Установить»** и **«Готово»**.

Приложение появится в меню «Пуск» под именем **Amadeus**. Ничего дополнительно устанавливать не обязательно — всё уже внутри установщика.

## 2. Первый запуск

При первом запуске откроется окно «Добро пожаловать в Amadeus». Там три шага:

1. **Язык интерфейса** — выберите **«Русский»**.
2. **Режим работы** — выберите **«Локальный пайплайн»**. Он работает без интернета и без ключа. Два других режима («Облачный адаптер» и «Realtime-адаптер») нужны только если у вас есть свой ключ провайдера.
3. **Свой ключ** — в локальном режиме оставьте поле пустым.

Нажмите **«Начать работу»**.

## 3. Подключение модели (чтобы ассистент отвечал)

Amadeus использует локальную модель через Ollama. Если Ollama ещё не установлена:

1. Зайдите на официальный сайт **ollama.com**, скачайте версию для Windows и установите её.
2. После установки Ollama запускается сама; её иконка появляется в трее.

Дальше в Amadeus:

1. Нажмите кнопку **«Настройки»** в левой панели (она подписана текстом).
2. Самый верхний блок называется **«Как запустить голос»**. Выполните его шаги по порядку:
   - **Шаг 1. Подключите Ollama.** В поле «Адрес Ollama» уже стоит `http://127.0.0.1:11434`. Нажмите **«Проверить подключение»**. Должно появиться сообщение «Ollama подключена. Моделей: …». Если написано «Не подключено» — запустите приложение Ollama и нажмите кнопку снова.
   - **Шаг 2. Выберите модель и подключите её.** В выпадающем списке выберите модель (например, `mimo-v2.6:latest`) и нажмите **«Подключить модель»**.
   - **Шаг 3. Выберите голос и проверьте микрофон.** В разделе «Голос» выберите голос и нажмите **«Проверить микрофон»**. Windows может спросить разрешение на доступ к микрофону — согласитесь.

После этого можно писать в чат и говорить.

## 4. Как пользоваться

- **Чат.** Введите сообщение в строке внизу и нажмите Enter.
- **Прикрепить файл или снимок.** Нажмите **«Файл»** у поля ввода и выберите «Файл», «Снимок экрана» или «Область экрана».
- **Голос.** Нажмите кнопку микрофона у поля ввода и говорите. Также работает кодовое слово **«Амадеус»**.
- **История.** Скрыта кнопкой **«История»** в левой панели; быстрое включение — `Ctrl+B`.
- **Поиск по истории** — `Ctrl+K`.
- **Показать/скрыть телеметрию** — `Ctrl+.`.
- **Во весь экран** — `F11`.
- В левой панели есть подписанные кнопки: **«Главная»**, **«История»**, **«Проект»**, **«Терминал»**, **«Центр»**, **«Настройки»**. В шапке есть кнопка **«Меню»** с остальными действиями.

## 5. Если что-то не работает

| Симптом | Что сделать |
| --- | --- |
| Ассистент не отвечает | Откройте «Настройки» → «Проверить подключение», затем «Подключить модель». |
| «Ollama не отвечает» | Запустите Ollama и повторите проверку. |
| Микрофон не слышно | Нажмите «Проверить микрофон» в настройках и разрешите доступ в Windows. |
| Голос не звучит | В разделе «Голос» выберите другой голос. |
| Windows ругается на установщик | Это предупреждение о неподписанной сборке; см. шаг 1.3. |

Все данные хранятся локально в `%APPDATA%\com.amadeus.assistant\data\amadeus.db`. Секреты — в системном хранилище ключей Windows, а не в базе данных.

## Что пока не проверено

Сборка установщика проверена в CI и локально. Поведение плавающего аватара «поверх всех окон» и прозрачность окна нужно проверить вручную на реальном Windows — CI это не тестирует.
