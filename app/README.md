# Амадеус — UI

Vite + React 19 + TypeScript. Дизайн-токены и примитивы перенесены из `replica/design`.

## Запуск

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm run build
npm run typecheck
```

## Подключение Ollama

Модель по умолчанию: `hf.co/nvidia/NVIDIA-Nemotron-3.5-Bolt-E4B-4GB:Q4_K_M`.

```bash
ollama pull hf.co/nvidia/NVIDIA-Nemotron-3.5-Bolt-E4B-4GB:Q4_K_M
ollama serve
```

Vite проксирует `/ollama` на `http://127.0.0.1:11434`, поэтому CORS не мешает.
Другая модель задаётся в `.env` (см. `.env.example`).

## Что уже работает

- Рабочее пространство: HUD, чат, стриминг ответа от Ollama, композер, телеметрия, темы.
- Свёрнутый режим: кнопка «Свернуть» или `Esc`; аватар-ядро в правом нижнем углу.
- Активация словом «Амадеус»: `idle → listening → thinking → speaking`. Без микрофона сценарий показывает клавиша `W`.
- Голосовая команда уходит в Ollama и добавляет диалог в историю; клик по ядру возвращает окно.
- Карточка «Модель» в правой панели: статус Ollama, наличие модели и команда загрузки.
- Мастерская: конструктор команд, Telegram, выбор аватара.
- Команды: фраза-триггер, горячая клавиша, действия «сказать» и «открыть ссылку». Срабатывают из чата, голосом, по хоткею и из Telegram. Хранятся в `localStorage`.
- Telegram: свой бот, chat id, проверка подключения, тестовое сообщение и приём команд, пока окно открыто. Токен не сохраняется.
- Аватар: переключатель «Ядро / Аватар». Персонаж нарисован с нуля на SVG; состояния читаются по глазам, антенне и рту.

## Tauri-каркас

`src-tauri/` содержит конфигурацию Tauri 2, иконки, capabilities и IPC-команды с тем же контрактом, что и HTTP API ядра. Оболочка собирается на Windows (нужны Rust + MSVC Build Tools):

```bash
cargo check   # в каталоге src-tauri, из Developer Command Prompt
cargo build
```

Реальные мосты: `invoke('app_health')` (в настройках), `notify_os` (уведомления ОС по напоминаниям и действиям), `capture_screen_base64` (кнопка снимка в композере), `window_hide`/`window_show`. Переход остальных команд с HTTP на `invoke()` ограничен одним файлом — `src/lib/api.ts`.

## Заглушки

- Распознавание речи — браузерный `SpeechRecognition`; в продукте — локальный keyword spotter через Tauri.
- Телеметрия — мок-данные, помечены «демо».
- Начальные сообщения в чате — демонстрационные; новые ответы приходят от модели.
- История диалогов и настройки пока не подключены к SQLite.
- Telegram ходит через прокси Vite. В некоторых сетях `api.telegram.org` недоступен без VPN — интерфейс покажет ошибку связи.
- Открытие ссылок в командах работает; запуск программ и ввод в другие окна появятся после Tauri-ядра.
